# Obra Companion v1.0
PWA offline-first para seguimiento de obra desde móvil.

Incluye proyectos, visitas, incidencias, fotografías, mediciones rápidas, actas/acuerdos, control documental, control económico, copias JSON e informe imprimible/PDF.

## GitHub Pages
Sube los cinco archivos de la raíz y la carpeta `assets`. Activa GitHub Pages sobre `main` y `/ (root)`.

Los datos profesionales se almacenan localmente en IndexedDB del dispositivo; no se publican en GitHub. Haz copias de seguridad periódicas.
